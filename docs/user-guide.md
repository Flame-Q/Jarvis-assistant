# Руководство пользователя

## 1. Что нужно

- Windows 10 или 11 (x64), Python **3.10**.
- Микрофон и колонки/наушники (для голосового режима).
- 16 ГБ RAM желательно; минимум ~4 ГБ свободно для Whisper + Ollama.
- Ollama, установленная пользователем, и модель `qwen2.5:3b-instruct`.
- Интернет только для первого скачивания моделей и для погоды/поиска.

Python 3.11+ не тестировался: в проекте зафиксированы версии под 3.10.0.

## 2. Установка

Открыть PowerShell в корне проекта (папка с `pyproject.toml`) и выполнить:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install --upgrade pip
.venv\Scripts\python.exe -m pip install -r requirements.txt
ollama pull qwen2.5:3b-instruct
.venv\Scripts\python.exe scripts\download_models.py
```

`requirements.txt` содержит `-e .`, поэтому команда `python -m jarvis` работает
без ручной настройки `PYTHONPATH`. ExecutionPolicy не меняется: python
вызывается напрямую из `.venv`.

Если Ollama ещё не установлена, установите её с официального сайта и запустите
`ollama serve` (обычно сервис стартует сам). Проект **не** устанавливает Ollama
и не использует `winget`.

### Если не скачиваются модели

HuggingFace может быть недоступен. Укажите зеркало **на один запуск**:

```powershell
$env:HF_ENDPOINT = "https://hf-mirror.com"
.venv\Scripts\python.exe scripts\download_models.py
```

Модель wake word (`hey_jarvis`, ~5 МБ) скачивается внутри пакета
`openwakeword`, Whisper small (~480 МБ) — в кэш HuggingFace.

## 3. Проверка железа

```powershell
.venv\Scripts\python.exe scripts\wakeword_check.py
.venv\Scripts\python.exe scripts\tts_check.py
```

`wakeword_check.py` показывает устройства ввода, пишет 5 секунд и печатает
score. Скажите «хей, Джарвис»; при score ниже порога уменьшите
`assistant.sensitivity` (например, 0.3). `tts_check.py` перечисляет голоса
Windows SAPI5 и произносит тестовую фразу через тот же провайдер, что и
ассистент.

## 4. Запуск

```powershell
# текст + голос (если микрофон доступен)
.venv\Scripts\python.exe -m jarvis

# только текст: удобно без микрофона
.venv\Scripts\python.exe -m jarvis --text

# иконка в трее
.venv\Scripts\python.exe -m jarvis --tray

# одна команда и выход (для проверки)
.venv\Scripts\python.exe -m jarvis --once "который час" --no-greeting
```

| Флаг | Значение |
|---|---|
| `--text` | не открывать микрофон, команды вводить текстом |
| `--voice` | принудительно включить голосовой режим |
| `--tray` | запустить трей и окно «Пульт микрофона» (нужен PySide6) |
| `--once "..."` | выполнить одну команду и выйти |
| `--no-greeting` | не произносить приветствие |
| `--config PATH` | другой файл конфигурации |
| `--log-level` | `DEBUG`, `INFO`, `WARNING`, `ERROR` |

Консоль оформлена через `rich`: при старте показывается баннер и таблица
зарегистрированных навыков. Во время записи выводится зелёное `[Слушаю...]`,
во время распознавания — жёлтый статус `Думаю...`. Таблицу можно вызвать
командами `help`, `?`, `помощь` или `команды`.

В консоли вводите команды текстом и нажимайте Enter. Выход — `q`, `quit`,
`exit`, «выход», `Ctrl+C` или голосом «заверши работу».

## 5. Активация

Есть три способа начать команду:

- **Кнопка «Говорить»** в окне «Пульт микрофона» (запуск с `--tray`).
  Первое нажатие начинает запись, второе — останавливает её и запускает
  распознавание. Ответ появится после остановки записи.
- **`Ctrl+Alt+Space`** — то же самое, если окно свёрнуто. Комбинация настраивается
  или отключается пустой строкой в `[assistant] manual_hotkey`.
- **Wake word «Хей, Джарвис»** или **`Ctrl+Alt+J`** — автоматическая запись:
  после активации говорите команду, запись закончится после 800 мс тишины
  или через 12 с.

Во время ответа ассистента микрофон приостановлен, чтобы не слышать сам себя.
Перебить речь голосом нельзя (barge-in не реализован); «стоп» работает, когда
ассистент молчит.

Если wake word срабатывает на шум или смех, откройте настройки и снимите
галочку **«Слушать «hey jarvis» (постоянно)»** — останутся только кнопка и
`Ctrl+Alt+Space`. Это рекомендуемый режим для демонстрации в шумной аудитории.

## 6. Команды

| Что сделать | Примеры фраз |
|---|---|
| Открыть программу | «открой дискорд», «запусти блокнот», «открой хром», «открой загрузки» |
| Обновить индекс | «обнови список программ» |
| Погода | «какая погода в Москве», «погода в Казани», «будет ли дождь» |
| Таймер | «таймер на 5 минут», «таймер на полчаса», «таймер на 90 секунд» |
| Напоминание | «напомни через час позвонить маме» |
| Громкость | «громкость 30», «сделай громче», «сделай тише», «выключи звук», «включи звук» |
| Время/дата | «который час», «какое сегодня число» |
| Скриншот | «сделай скриншот» |
| Поиск | «найди в интернете рецепт борща», «включи на ютубе джаз» |
| Заметки | «запиши заметку купить хлеб», «что у меня на сегодня», «выполни заметку 1» |
| Питание | «заблокируй компьютер», «выключи компьютер», «перезагрузи компьютер» |
| Чат | «объясни, что такое инкапсуляция», «чем отличается список от кортежа» |
| Стоп | «стоп», «хватит» |
| Выход | «заверши работу»; в консоли — `q`, `quit`, `exit`, «выход» |
| Shell | «выполни команду …» — только если включён и разрешён |

Опасные действия (выключение, перезагрузка, shell) требуют ответа «да».
Ответ «нет», «отмена» или «стоп» отменяет действие. Если ответить чем-то
другим, ассистент переспросит.

### Discord и другие приложения

Порядок поиска: алиас из конфига → меню «Пуск» → UWP/AppID → PATH → URI.
Discord открывается через `discord://`; если deep link не зарегистрирован,
используется `%LocalAppData%\Discord\Update.exe --processStart Discord.exe`
(без хардкода версии). Сложные действия внутри Discord не поддерживаются.

Чтобы добавить своё приложение, пропишите алиас в `config/config.toml`:

```toml
[skills.aliases]
"моя программа" = "C:\\Tools\\MyApp\\MyApp.exe"
"рабочий чат" = "Telegram"
```

После изменения индекса скажите «обнови список программ».

## 7. Трей и настройки

При запуске с `--tray` появляется синяя иконка «J» и небольшое окно
**«Пульт микрофона»**. Меню трея:

- **Пульт микрофона** — показать/скрыть окно с кнопкой «Говорить».
- **Статус** — состояние FSM, модель, доступность Ollama, голос, hotkey, wake word.
- **История** — последние 20 реплик и 10 команд из SQLite.
- **Настройки** — модель, голос, hotkey, кнопка «Говорить», город, порог wake word,
  скорость речи, постоянное прослушивание wake word.
- **Открыть журнал** — `data/jarvis.log` в блокноте.
- **Выход** — корректно останавливает циклы, TTS и БД.

Настройки сохраняются в `config/config.toml` и применяются сразу: модель,
город, голос, скорость, порог, режим wake word и горячие клавиши. Если
голосовой цикл запущен, новые комбинации перерегистрируются.

## 8. Конфигурация

Скопируйте `config/config.example.toml` в `config/config.toml` (файл в
`.gitignore`). Все ключи необязательны.

| Секция | Ключи | Комментарий |
|---|---|---|
| `[assistant]` | `name`, `wake_word`, `wake_word_enabled`, `sensitivity`, `hotkey`, `manual_hotkey`, `language`, `data_dir` | `sensitivity` — порог 0..1, меньше = чувствительнее; `wake_word_enabled = false` — только кнопка/клавиша |
| `[stt]` | `model`, `compute_type`, `device`, `language`, `beam_size`, `vad_silence_ms`, `max_utterance_s`, `manual_max_utterance_s` | `small`/`int8`/`cpu` — проверенная комбинация; `manual_max_utterance_s` — аварийный лимит записи по кнопке |
| `[tts]` | `provider`, `voice`, `rate`, `volume` | `provider` — `sapi5` (по умолчанию), `pyttsx3` (резерв) или `edge`; `voice` — подстрока id, `ru` для русского |
| `[llm]` | `provider`, `base_url`, `model`, `num_ctx`, `keep_alive`, `temperature_chat`, `temperature_tools`, `history_turns`, `timeout_s` | `base_url` без `/v1` |
| `[weather]` | `default_city`, `cache_ttl_s` | Open-Meteo, без ключа |
| `[skills]` | `shell_enabled` | по умолчанию `false` |
| `[skills.aliases]` | пары «алиас = цель» | цель: имя программы, путь, URL или URI |
| `[ui]` | `tray`, `theme` | тема пока информативная |
| `[logging]` | `level`, `file` | файл можно смотреть в трее |

## 9. Демонстрационный сценарий

1. Запустить `python -m jarvis --tray`.
2. Нажать **«Говорить»** в окне пульта, задать вопрос и нажать **«Остановить»**.
   Либо сказать «**Хей, Джарвис**» — сигнал.
3. «**Открой дискорд**» — Discord/URI.
4. «**Открой хром**» — Chrome.
5. «**Какая погода в Москве**» — прогноз (нужен интернет).
6. «**Таймер на 5 минут**» — подтверждение; через 5 минут напоминание.
7. «**Громкость 30**» — громкость Windows 30 %.
8. «**Сделай скриншот**» — PNG в `data/screenshots/`.
9. «**Объясни, что такое инкапсуляция**» — ответ LLM по предложениям.
10. «**Стоп**» (когда молчит) — остановка речи; «**Заверши работу**» — выход.

Для защиты лучше заранее прогреть модели: запустить ассистента, дать ему
2–3 секунды и один раз вызвать чат. Тогда Whisper и qwen уже в памяти.

## 10. Диагностика

| Симптом | Что делать |
|---|---|
| Нет русского голоса | Параметры Windows → Время и язык → Речь → Добавить голоса → Русский. Затем `scripts\tts_check.py`; в `[tts] voice` можно указать «irina» |
| Текст ответа есть, озвучки нет | Проверить устройство вывода Windows: сейчас TTS идёт на устройство по умолчанию (в этой системе — наушники EarPods), а не обязательно на колонки. Запустить `scripts\tts_check.py`; если фразы не слышно, проверить громкость и `[tts] volume`. В логе должна быть строка `TTS finished`; если её нет — пришлите фрагмент `data/jarvis.log` |
| Wake word не срабатывает | Сказать «hey jarvis» ближе к микрофону; понизить `sensitivity` до 0.3; проверить `wakeword_check.py`; использовать `Ctrl+Alt+J` или кнопку «Говорить» |
| Wake word срабатывает на смех/шум | Поднять `sensitivity` до 0.55–0.65 или снять галочку «Слушать «hey jarvis»»; использовать кнопку/`Ctrl+Alt+Space` |
| Кнопка «Говорить» не реагирует | Дождаться окончания ответа (кнопка показывает «Говорю…»); проверить, что ассистент запущен без `--text`; микрофон не занят |
| Микрофон занят | Закрыть приложения, захватившие устройство; проверить устройства в `wakeword_check.py`; запустить `--text` |
| Ollama недоступна | `ollama list`, `ollama serve`; проверить `http://127.0.0.1:11434/api/tags`; в логе будет «LLM ready» |
| Модель не найдена | `ollama pull qwen2.5:3b-instruct`; имя в `[llm] model` должно совпадать |
| Чат медленный | Закрыть лишние программы; `keep_alive = "30m"`; ответы ограничены системным промтом; 3B — компромисс |
| Погода/поиск не работают | Это сетевые функции; проверьте интернет. Команды и чат офлайн работают |
| HF не скачивает Whisper | `HF_ENDPOINT=https://hf-mirror.com` и повторить `download_models.py` |
| Погода показывает не тот город | Уточните: «погода в Казани»; проверьте `default_city`; после смены города в настройках кэш обновится через 10 минут |
| Discord не открывается | Проверить `discord://` в браузере; прописать полный путь к `Update.exe` в алиасах; «обнови список программ» |
| Приложение Store не запускается | «обнови список программ»; некоторые UWP требуют `explorer.exe shell:AppsFolder\...` и могут не реагировать |
| Краказябры в консоли | Запускать в Windows Terminal или выполнить `chcp 65001`; логи пишутся в UTF-8 |
| Трей не появился | Установить GUI: `.venv\Scripts\python.exe -m pip install ".[gui]"`; при ошибке приложение продолжит в консоли |
| Нет напоминания после перезапуска | Таймеры живут в памяти процесса; после перезапуска пропущенные не догоняются (ограничение) |

Журнал: `data/jarvis.log` (уровень меняется в `[logging]`).

## 11. Приватность и данные

- Микрофон записывается только после активации; аудио обрабатывается в памяти и
  **не сохраняется** (кроме тестового `data/stt_sample.wav`, создаваемого вручную).
- Диалог, команды, заметки и таймеры — в `data/jarvis.db`; индекс программ — в
  `data/apps.json`; скриншоты — в `data/screenshots/`.
- В интернет уходят только запросы погоды (Open-Meteo) и команды поиска,
  инициированные пользователем. LLM — локальная Ollama.
- `config/config.toml` и `data/` исключены из git. Секретов в проекте нет.

## 12. Удаление

```powershell
Remove-Item -Recurse -Force .venv
Remove-Item -Recurse -Force data
```

Модели Ollama удаляются командой `ollama rm qwen2.5:3b-instruct`; кэш Whisper —
в `%USERPROFILE%\.cache\huggingface`. Конфиг можно удалить отдельно.
