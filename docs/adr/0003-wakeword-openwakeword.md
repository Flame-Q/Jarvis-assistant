# ADR 0003. Wake word

- **Статус:** принято
- **Дата:** 2026-10-26
- **Контекст:** P2, FR-1, NFR-1, NFR-7

## Контекст

Нужна активация фразой «хей, Джарвис» без облака, аккаунтов и API-ключей.
Желательна задержка ≤ 0.5 с и низкая нагрузка на CPU. Микрофон уже отдаёт
16 кГц mono блоками по 20 мс, рядом работает VAD.

## Рассмотренные варианты

| Вариант | Плюсы | Минусы |
|---|---|---|
| Picovoice Porcupine | точность, готовые модели | с 30.06.2026 бесплатный тариф закрыт, нужен ключ и аккаунт |
| openWakeWord + ONNX | бесплатно, офлайн, модель `hey_jarvis`, активное сообщество | английская тренировка, требует окон 80 мс |
| Vosk keyword spotting | один движок с STT | крупнее, выше задержка, хуже на «hey jarvis» |
| Собственная модель | полный контроль | требует датасета и обучения, избыточно для личного проекта |

## Решение

Использовать **openWakeWord** (`onnxruntime`) с моделью `hey_jarvis`, порог
`0.4` (настраивается). Микрофонный цикл отдаёт 20-мс блоки; детектор
накапливает четыре блока в окно 1280 сэмплов (80 мс) и вызывает модель только
на целом окне. Это соответствует требованию библиотеки и даёт задержку
обнаружения не более одного окна (80 мс). Горячая клавиша `Ctrl+Alt+J` —
резервный путь активации.

## Последствия

- Полностью офлайн, без ключей; модели ~5 МБ скачиваются один раз.
- На синтетическом клипе «Hey Jarvis» (TTS, 16 кГц) максимум score 0.999,
  порог 0.4 пересечён на 0.72 с от начала клипа; проверено синтетическим
  стендом (см. `docs/testing.md`), а `wakeword_check.py` служит для проверки
  реального микрофона.
- Английская тренировка: русское «Джарвис» может не срабатывать; в README
  рекомендуется произносить «хей, Джарвис» с английским «hey».
- Возможны ложные срабатывания в шумной комнате; порог и sensitivity настраиваются.
  Для шумной аудитории wake word можно отключить (`wake_word_enabled = false`)
  и использовать push-to-talk кнопку/`Ctrl+Alt+Space` (ADR 0007).
- Модель можно заменить через `assistant.wake_word`, не меняя цикл.
- При сбое загрузки модели голосовой режим отключается, но hotkey и текст
  продолжают работать (degraded).
