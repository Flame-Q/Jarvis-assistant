# ADR 0001. Распознавание русской речи

- **Статус:** принято
- **Дата:** 2026-10-26
- **Контекст:** P2, FR-2, NFR-2, NFR-7

## Контекст

Ассистенту нужно офлайн распознавать русскую речь на CPU (16 ГБ RAM, без
дискретной GPU), с задержкой около 1–2 секунд на фразу из 3–5 секунд и без
API-ключей. Микрофон отдаёт 16 кГц mono int16 блоками по 20 мс. Точность важна
для названий программ и чисел («громкость 30», «таймер на 5 минут»).

## Рассмотренные варианты

| Вариант | Плюсы | Минусы |
|---|---|---|
| Vosk small-ru | лёгкий (~50 МБ), быстрый, streaming | заметно хуже на именах и шуме, устаревшие модели |
| faster-whisper small int8 | хорошее качество, CPU, поддержка RU, простой API | ~480 МБ, 1.5–3 с на фразу, не streaming |
| whisper.cpp | быстрый на CPU, офлайн | сборка/бинарники под Windows, сложнее интеграция и тесты |
| Windows SAPI / SpeechRecognition | встроено | требует онлайн-распознавания или языковой пакет, качество ниже |

## Решение

Использовать **faster-whisper** с моделью `small`, `device=cpu`,
`compute_type=int8`. Модель загружается лениво и прогревается в фоновом потоке
при старте голосового режима. VAD выполняется отдельно (`webrtcvad-wheels`) на
20-мс кадрах; запись завершается после 800 мс тишины, максимум 12 с.
`condition_on_previous_text=False`, `vad_filter=False` (VAD уже снаружи),
`beam_size=1` для скорости.

## Последствия

- Первый запуск скачивает ~480 МБ (документировано в quickstart); далее офлайн.
- Холодная загрузка ~2.9 с, тёплое распознавание ~1.5 с для 3.7-с фразы.
- RSS процесса после прогрева Whisper и wake word — около 524 МБ.
- Нет потокового распознавания: текст появляется после конца фразы. Для
  barge-in/стриминга в будущем можно добавить Vosk или Whisper streaming.
- Галлюцинации на тишине отсекаются VAD и проверкой пустого текста.
- Модель можно заменить через `[stt] model`, не меняя ядро (Strategy/Adapter).
