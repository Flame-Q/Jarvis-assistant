# ADR 0005. Графический интерфейс и трей

- **Статус:** принято
- **Дата:** 2026-10-26
- **Контекст:** P5, FR-13, FR-14, NFR-4

## Контекст

Нужен системный трей, окно настроек (модель, голос, горячая клавиша, кнопка
«Говорить», город, порог wake word), окно истории и компактный пульт
push-to-talk. Приложение должно оставаться работоспособным без GUI и без
микрофона. Установка не должна требовать Visual Studio Build Tools.

## Рассмотренные варианты

| Вариант | Плюсы | Минусы |
|---|---|---|
| PySide6 (Qt 6) | нативный трей, богатые виджеты, LGPL, wheels под Python 3.10 | ~200 МБ, отдельная зависимость |
| Tkinter | встроен, лёгкий | слабый трей, устаревший вид, больше ручного кода |
| Веб-UI (FastAPI + браузер) | кроссплатформенно | лишний сервер, не «настольное» приложение |
| Без GUI, только консоль | минимум зависимостей | не выполняет FR-13/FR-14 |

## Решение

Использовать **PySide6** как опциональный extras `gui`; в `requirements.txt`
он включён, чтобы демонстрация работала «из коробки». Трей запускается флагом
`--tray`; без флага доступен консольный режим. Вместе с треем открывается
компактное окно **«Пульт микрофона»** с кнопкой «Говорить»: первое нажатие
запускает запись, второе — останавливает и передаёт аудио в STT. Настройки
пишутся в `config/config.toml` (полный дамп текущей конфигурации), применяются
на лету: модель, город, голос, скорость, порог и включение wake word, обе
горячие клавиши; они перерегистрируются, если голосовой цикл активен. История
и журнал команд читаются из SQLite и показываются в отдельном окне.

## Последствия

- GUI изолирован в `ui/` и исключён из строгой проверки mypy; ядро от него
  не зависит.
- При отсутствии PySide6 (`pip install` без GUI) приложение не падает:
  импорт трея выполняется лениво, при ошибке — консольный fallback.
- Трей не завершает процесс по закрытию окна (`setQuitOnLastWindowClosed(False)`);
  выход — через меню, которое корректно останавливает циклы и TTS.
- Горячая клавиша меняется без перезапуска только при активном голосовом цикле;
  иначе — после перезапуска (честно указано в README).
- PySide6 распространяется по LGPL; для курсовой это допустимо, динамическая
  линковка не требует открытия кода.
